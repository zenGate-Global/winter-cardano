Here you set your immutable data for your commodity using ObjectDatum.

```typescript
const walletAddress = await eventFactory.getWalletAddress();
const walletAddressPkHash = await eventFactory.getAddressPkHash();

const objectDatum = EventFactory.getObjectDatumFromParams({
    protocolVersion: 1,
    dataReferenceHex: 'deadbeef',
    eventCreationInfoTxHash: '',
    signersPkHash: [walletAddressPkHash]
});
```

## Usage

The objectDatum is passed directly to `mintSingleton()`:

```typescript
const walletUtxos = await eventFactory.getWalletUtxos();
const unsignedTx = await eventFactory.mintSingleton('myToken', walletUtxos, objectDatum);
```
