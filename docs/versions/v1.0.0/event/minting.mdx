A token known as a singleton must be minted to the contract to easily identify the proper utxo. It is known as a singleton since only one of them will be in existence just as an NFT.

<Alert variant="warning">Continue only if the entire instantiation step is complete. It is important that your smart contract parameters are correctly set.</Alert>

## Transaction Building

```typescript
const name = 'testSingletonTracker';
const walletUtxos = await eventFactory.getWalletUtxos();

const unsignedTx = await eventFactory.mintSingleton(name, walletUtxos, objectDatum);
const signedTx = await eventFactory.signTx(unsignedTx);
const txHash = await eventFactory.submitTx(signedTx);
```
